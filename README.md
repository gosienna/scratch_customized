# scratch_customized

A browser-based, Scratch-compatible coding platform for programming learners, forked from the
[Scratch editor monorepo](https://github.com/scratchfoundation/scratch-editor).

- Three switchable editor modes: **Original** Scratch, **Custom** (default), and **Text** (Python-style / JavaScript-style)
- Saved `.sb3` files stay 100% compatible with scratch.mit.edu and Scratch Desktop
- Projects can be stored in browser IndexedDB, a local folder, or Google Drive, with Git-based version history

See [PLAN.md](PLAN.md) for the design, and [UPSTREAM_README.md](UPSTREAM_README.md) for the upstream monorepo documentation.
